# Cartella Tracce Audio Personalizzate di Annina 🎵

In questa cartella puoi inserire i tuoi file audio musicali preferiti per ogni "mood":

1. **BADDIE**: Inserisci il file `baddie.mp3` in questa cartella (oppure dentro `assets/audio/baddie/track.mp3`)
2. **CATTIVA**: Inserisci il file `cattiva.mp3` in questa cartella (oppure dentro `assets/audio/cattiva/track.mp3`)
3. **ESPANOL**: Inserisci il file `espanol.mp3` in questa cartella (oppure dentro `assets/audio/espanol/track.mp3`)

Formati supportati: `.mp3`, `.ogg`, `.wav`, `.m4a`.
Il gioco riprodurrà automaticamente la traccia selezionata in loop continuo con volume regolabile e toggle ON/OFF!
